## 正式字段与清空动作

`ResearchContext` 新增以下字符串字段，旧数据缺省为空：

| 字段 | 含义 |
|---|---|
| `research_orientation` | 用户自述学术取向或传统 |
| `target_institution` | 用户的目标院校，简称保留原表达 |
| `target_department` | 目标院系 |
| `target_degree` | 目标学位，不从用户现有学历补出 |
| `target_advisor` | 用户明确关注的导师，不表示存在任职或招生关系 |

写入和更正经 `sanitize_context_patch` 统一校验。普通字段仍拒绝直接写入空白字符串；
学术字段撤回使用独立写入动作：

```json
{"clear_fields": ["target_advisor", "research_orientation"]}
```

`clear_fields` 必须为上述五个字段的非空、不重复列表，不能与本次设置的同名字段重叠。
整次校验通过后转换为相应字段的空字符串，再交给仓储；动作本身不落盘。
一个非法项会拒绝整次 patch。Web 回合工具的清空操作继续使用暂存区，取消后丢弃。
基本信息面板将用户删除已存学术字段的操作转换为这一显式动作。

## 抽取行为与运行时边界

核心输入“我的取向是华南学派，想申请香港中文大学历史系”会得到学术取向、院校和院系，
不会从“香港”“华南”填田野地点或区域，也不会从申请历史系推定用户的学科背景。
明确自述历史学背景可以保存为 `discipline=历史学`。

“申请香港中文大学历史系，田野在福建”分别保存院校和福建；显式田野地点优先于同轮出行地点。
“中大”“港中文”“CUHK”等按原表达保存，本批不做实体消歧或学术关系推断。
规则限定在明确陈述格式，疑问、假设、他人建议不自动升级为用户选择。

学术背景的明确重述可以覆盖旧值；其他原有规则槽位继续采用增量行为。
既有地点可能来自用户真实确认，本批不会因发现院校/学派名称而删除旧地点或区域。

研究摘要与方案上下文已包含新增字段；对应工具提示使用通用背景规则。
CLI 仍在回合前抽取，Web 仍在成功轮末抽取。本轮首次回答前的共享背景准备和证据检索
属于后续 R10–R12，不在本批宣称实现的能力中。

本批未调用外部模型或付费服务，没有新增密钥，也没有读取或复制私有语料。
未来受限语料可以使用已有 Tier S 私有资产机制，具体知识包加载接口待 M2 定义。
